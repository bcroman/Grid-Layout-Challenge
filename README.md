# CSS Grid Layout Challenge

## Project Description
This project is a CSS Grid Layout Challenge built using HTML and CSS. 

The aim of this challenge was to recreate a webpage layout, based on a provided wireframe using CSS Grid.

The project focuses on creating multi-column layouts, positioning grid elements, controlling spacing and alignment, and building responsive designs for different screen sizes.

## Features
- Multi-column CSS Grid layout
- Different grid item sizes and positions
- Five-column desktop grid layout
- Responsive two-column mobile layout
- Invite Users form
- Three progress indicator circles
- Responsive design using media queries

## Technologies Used
- HTML5
- CSS3
- CSS Grid
- CSS Media Queries
- HTML5 Form Elements

## How to Run
1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. View the CSS Grid layout.
5. Resize the browser to test responsiveness.
6. Test the Invite Users form fields.
